Privacy

What KSM stores

KSM stores tournament names, competitor names and dojos, and match scores. There are no user accounts yet.

Who can see it

Anyone with a tournament link can view its information. Staff use a password to edit the tournament.

Where it is stored

Shared tournament data is stored on Cloudflare. KSM also saves tournament data in your browser for local use and recovery.

Request deletion

Contact the Hawaii Kendo Federation (HKF) to ask for deletion. Include the tournament name or link so HKF can identify the data.

Planned sign-in

Sign-in via Auth0 and Google is planned but is not available yet. This notice will be updated when sign-in is introduced.
