Privacy

Last updated: October 12, 2026

What KSM stores

KSM stores tournament details; competitor and team member names and dojos; match scores, results, placements and special awards; exhibition matches; and referee names entered in Setup. There are no user accounts yet.

KSM also stores technical device labels and IDs for synchronisation. Staff passwords are stored as hashes; new passwords use salted hashes, and older hashes are upgraded after a successful login.

Some competitors are minors. Organisers should enter only the name and dojo needed to run the event.

Who can see it

Tournaments are listed publicly on this site's home page. Anyone can open them and view tournament information, including competitors' names, dojos and results. Staff need the tournament's password to make changes.

Where it is stored

Shared tournament data is stored on Cloudflare. KSM also saves tournament data in your browser for local use and recovery.

Request deletion

Use the Hawaii Kendo Federation (HKF) contact page to ask for deletion. Include the tournament name or link so HKF can identify the data.

Planned sign-in

Sign-in via Auth0 and Google is planned but is not available yet. This notice will be updated when sign-in is introduced.
