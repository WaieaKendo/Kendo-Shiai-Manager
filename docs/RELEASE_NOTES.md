# KSM v3.10.7 Release Notes

This release improves Live Scores on phones and applies a shared, progressive ordering rule to individual pool Court Context.

## Live Scores

- Compact portrait and landscape typography.
- White remains left; Red remains right.
- Current match and Next Match remain visible.
- Standard team events show a read-only current bout, the full team lineup, bout points, team wins, and team points.

## Pool Context

- Incomplete pools appear alphabetically above the Championship Bracket.
- Each completed pool moves below the bracket with a checkmark.
- Completed pools remain in alphabetical order.

No tournament logic or Match Object schema changed.
